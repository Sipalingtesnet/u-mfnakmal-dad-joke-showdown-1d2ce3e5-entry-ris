# Dad Joke Showdown

This entry is a single dad joke, written to be told out loud across a
dinner table. It is a household joke built around the word "pressing,"
which carries two meanings at once: the physical act of ironing a shirt
flat, and the legal act of pressing charges. The setup is short and
concrete — a shirt ironed so hard it files a complaint — and the
punchline arrives on the very last word, so the turn lands on the first
read without anyone explaining it.

The joke stays inside the dad joke tradition: a straight-faced setup, a
clean double meaning, and a groan that earns its place. It is original,
not a retelling of a familiar classic, and it reads naturally aloud with
a rhythm a father could deliver while passing the potatoes. Every
word earns its place; nothing is padded for length.

> I ironed my shirt so hard it filed a complaint — it said I was pressing charges.

## How it works

`main.py` is a minimal, deterministic Python 3 program that uses only the
standard library. It holds the joke as a string literal, self-checks the
competition gate (non-empty, not only whitespace, no newline, 1-200
Unicode code points), creates `/output` if needed, and writes the joke to
`/output/entry.txt` with no trailing newline. Running it twice produces
byte-identical output.
